# Reading Lab v1.5.1 — iPhone・GitHub Pages向け公開用

このフォルダは **GitHub PagesなどのHTTPS静的ホスティングにそのまま置ける** Reading Lab の公開用ファイルです。アプリのコードと内蔵辞書のみで、個人の教材・単語・学習履歴は含まれません。

## 1. GitHub Pagesで公開する（初心者向け）

1. GitHubにログインして、新規リポジトリ（例：`reading-lab`）を作成する。GitHub Pagesを利用できる公開範囲のリポジトリを選ぶ。
2. このZIPを解凍し、**フォルダ自体ではなく、中身の `index.html`, `app.js`, `styles.css`, `icons/` などをリポジトリのルートにアップロード**する。
3. リポジトリの **Settings → Pages** を開き、**Build and deployment → Source: Deploy from a branch** を選ぶ。**Branch: main / (root)** を選び、Saveする。
4. Pagesが公開済みになったら、表示されたHTTPSのURLをSafariで開く。典型例は `https://<ユーザー名>.github.io/reading-lab/`。

**重要：** `Reading_Lab_v1.5.1_site/` というフォルダを丸ごとルート直下にアップロードすると、上記のURLでは動きません。`index.html` がリポジトリのルートにある状態にします。公開にはGitHubアカウントとリポジトリ操作が必要で、このZIP自体が公開URLを作るわけではありません。

GitHub Pages以外のHTTPS静的サイトにも、同じファイル構成で配置できます。GitHubの公開リポジトリでは**コードや同梱ファイルは第三者が閲覧できます**。APIキー、バックアップJSON、私的な教材、`.private_sync` は絶対に公開リポジトリにアップロードしないでください。

## 2. iPhoneのホーム画面に追加

1. iPhoneの **Safari** で上記のHTTPSサイトを開く。
2. Safariの **共有ボタン** をタップする。
3. **「ホーム画面に追加」→「追加」** を選ぶ。
4. ホーム画面の **Reading Lab** アイコンをタップして利用する。

初回は通信が必要。以降はService Workerでキャッシュしたアプリ本体と内蔵辞書をオフラインでも利用できます。オンライン英英辞書・外部の翻訳ページ・PDF.js初回取得などは通信が必要です。iPhoneのプライベートブラウズやアプリ内ブラウザは、保存・インストールに向きません。

追加の案内は **設定 →「追加方法を見る」**、または初回に上部へ出る案内からも表示できます。

## 3. iPhoneで教材・単語を使う

- 「教材」でテキストを貼り付ける、TXT/EPUBを読み込む。PDFは文字入りPDFのみ（PDF.jsにオンライン接続が必要）。
- 英文の単語をタップして意味を確認。長押し／範囲選択後、画面下の補助ボタンで和訳・構文・マーカー・保存。
- 「復習」で単語帳、階層フォルダ、フラッシュカードを利用。
- **設定 →「共有して保存」→ iOS共有メニュー →「ファイルに保存」** でJSONバックアップを保存。非対応ブラウザではJSONのダウンロードに切り替わります。
- **設定 →「バックアップを復元」** でJSONを読み込みます（既存データは置換されます）。

学習データは原則として **使用したブラウザ／端末の保存領域** に置きます。GitHub Pagesのリポジトリや運営者のサーバーに教材・学習記録を自動送信する仕組みはありません。Safari版、ホーム画面版、別端末、旧 `file://` HTML版では保存領域が異なることがあるため、移行時はJSONバックアップを使ってください。OSの空き容量不足、サイトデータ削除、PWA削除により消える可能性があるので、定期的にバックアップしてください。

## 4. GitHub Pages版の制限

- **AIによる自然な和訳・自動構文解析／AI問題生成は利用できません**。OpenAI APIの秘密鍵を守るため、静的公開サイトにAPIキーを埋め込んでいません。AIが必要ならNodeサーバー版をHTTPSで動かす別途の設定が必要です。
- **PCとスマホの自動同期はありません**。端末間の受け渡しはバックアップJSONで行います。
- PWAの初回導入・最終的なiOSの「ホーム画面に追加」動作は、実機のSafariとHTTPS公開後に確認してください。
- Service Workerのキャッシュは本体コード・画像・辞書だけです。学習データの自動サーバー送信・バックアップは行いません。

## 5. 更新方法

GitHub Pagesのファイルをv1.5.1から新バージョンに上書きします。保存済みの学習データは同じサイトURL・同じ端末の保存領域を利用しますが、**更新前にJSONを書き出してください**。別のリポジトリ名やURLへ移動すると保存領域が変わります。新しいService Workerによる更新は通信状態によって反映に時間差が生じることがあります。
